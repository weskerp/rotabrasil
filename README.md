# Rota Brasil — Landing page demonstrativa

Landing page de vendas fictícia para um e-book de turismo, criada em React + Vite.

## Requisitos
- Node.js 18 ou superior
- npm

## Executar localmente
```bash
npm install
npm run dev
```

## Gerar versão de produção
```bash
npm run build
npm run preview
```

## Publicar na Vercel
1. Envie o projeto para um repositório GitHub.
2. Na Vercel, importe o repositório.
3. Framework Preset: Vite.
4. Build Command: `npm run build`.
5. Output Directory: `dist`.
6. Clique em Deploy.

## Personalização antes de apresentar a um cliente
- Substituir nome, textos, preço e conteúdo fictício pelo material real do cliente.
- Substituir as imagens ilustrativas por imagens licenciadas/fornecidas pelo cliente.
- Trocar o botão demonstrativo pelo link real de checkout da Hotmart.
- Criar mockup final com a capa e identidade visual reais do e-book.
- Atualizar metadados, redes sociais e contatos.

## Observações
- O checkout da Hotmart não está integrado. O botão de compra abre um aviso de demonstração.
- Os depoimentos não foram incluídos para evitar avaliações inventadas.
- Marca, produto, preço e conteúdo são fictícios.
- As imagens são carregadas de URLs do Unsplash e exigem conexão com a internet.
